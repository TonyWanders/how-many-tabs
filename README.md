A program that writes one number, digits only, the honest count of open browser tabs, to `/output/entry.txt`, for the make.fun competition [How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

## Run it

```sh
python3 main.py
```

It writes the tab count below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The tab count is 2 characters, inside the 1 to 5 gate.
